# file2quiz

> 将各种文档/题库（PDF）转换为现代化移动端离线刷题应用。**纯扁平化设计、无渐变、无任何阴影、杜绝任何 Emoji**，采用全套精巧原生 SVG 矢量图标。深度支持时政金句联网与无过期年份展示、做题模式顶栏 AI 纯文字菜单、一键 AI 解析按钮与悬浮名师助教多轮对话、设置板块内置完整 AI 配置、每日打卡统计、全局题目搜索、艾宾浩斯遗忘曲线复习、全真模拟组卷保存、学情考分预测、AI 品牌多服务商与外部题库导入。

- 📦 **GitHub 仓库**：[Simple53/file2quiz](https://github.com/Simple53/file2quiz)
- 🛠 **开发与运行环境**：现代极速包管理器 **uv** (Python 3.13)

### 1. 首页与时政研学 Banner

- 🤖 **做题模式顶栏 AI 配置按钮与纯文字名称菜单**：

- ⚡️ **精简一键解析按钮 + 悬浮 AI 名师助教 (多轮对话)**：
  - 题目下方答案区精简为【一键 AI 深度解析与助教追问】胶囊按钮；
  - 支持右下角悬浮 AI 助教球与半屏对话抽屉；
  - 自动代入当前题目的题干、选项、正确答案与官方考点，生成深度精讲；
  - **支持自由多轮对话追问**（如“为什么不选B？”、“这个知识点怎么区分？”），大模型结合上下文打字机流式输出；
  - 抽屉支持清空对话与最小化收起；
  - **设置总开关**：在设置板块中可随时开启或关闭悬浮 AI 助教。
- 🔄 **手势与平铺工具栏**：
  - 题目区域支持**左右滑屏切题**；
  - 顶部平铺：返回退出、计时器、草稿画板（**支持单步撤销 Undo**）、星标收藏、太阳/月亮/护眼主题专属图标切换、答题卡。

## 二、 手机端访问与网络解决方案

### 1. 局域网访问（解决同一 WiFi 无法访问的问题）
- **现象原因**：若连接的是**校园网/公共 Wi-Fi（如 NNU-WiFi6）**，无线交换机普遍启用了 **AP 隔离 (Client Isolation)**，该功能禁止同 WiFi 下的手机与电脑通过内网 IP 相互通信；此外 Windows 默认对公用网络防火墙阻断端口。
- **最快 1 秒解决办法：开启电脑“移动热点”**
  1. 在电脑 Windows 设置中打开 **【移动热点】**；
  2. 手机 Wi-Fi 连接电脑发出的这个热点；
  3. 手机浏览器直接访问热点分配的网关地址：`http://192.168.137.1:8080`（或当前热点网卡 IP）。
  - *因为热点属于纯内网私有连接，绝无任何 AP 隔离，100% 能够瞬间秒开！*

### 2. 彻底的非局域网公网方案：GitHub Pages 免费托管（极力推荐）
本项目是**纯前端轻量化 PWA 应用**，无需任何后端服务器支撑，所有刷题进度和配置均保存在手机本地，直接使用 GitHub Pages 托管最完美：
- **全球公网 HTTPS**：手机无论用 4G/5G 流量还是任意 WiFi 随时随地都能访问；
- **原生添加到主屏幕 (PWA)**：在 Safari 或 Chrome 点击“添加到主屏幕”，无需开启电脑，甚至**在手机断网、完全无信号的情况下也能离线秒开刷题**！

#### 开启步骤：
1. 打开您的 GitHub 仓库：[Simple53/file2quiz](https://github.com/Simple53/file2quiz)；
2. 进入 **Settings** ➔ **Pages**；
3. 在 **Build and deployment** 下方的 **Source** 选择：
   - **GitHub Actions**（推荐，仓库内已内置 `.github/workflows/deploy.yml` 自动打包发布 `web/`）；
   - 或选择 **Deploy from a branch** ➔ 分支选 `main` ➔ 目录选 `/ (root)`。
4. 部署完成后，即可在手机浏览器打开专属的全球公网链接：
   `https://simple53.github.io/file2quiz/`
