# 笃学题库 (Duxue Quiz)

> 深度参考**粉笔 App**交互与视觉规范打造的现代化专业刷题工具。**纯扁平化设计、无渐变、无任何阴影、杜绝任何 Emoji**，采用全套精细 SVG 矢量图标，支持双做题模式、掌握度星级评定、艾宾浩斯遗忘曲线复习与 AI 名师流式深度解析。

- 📦 **GitHub 仓库**：[Simple53/file2quiz](https://github.com/Simple53/file2quiz)
- 🛠 **包管理工具**：基于现代极速工具 **uv** 构建

---

## 一、 功能与界面亮点 (粉笔风格深度复刻)

### 1. 课程列表首页 (查漏补缺 专项提升)
- **掌握度星级评估**：每个科目根据用户的历史做题正确率动态评定并点亮 **1~5 颗星级**，直观掌握知识点薄弱项。
- **精准进度追踪**：展示已答题数/总题数（如 `35/220`），并提供 **【继续上次 ›】** 快捷入口，一键秒回上次离开的题号。
- **全真题库内置**：已收录 5 大高校教资与公考科目共 1100 道真题（单选、多选、判断）。

### 2. 刷题工作台 (顶部专业工具栏)
- **计时器**：正向秒级计时器（`00:03`），实时把控做题速度。
- **草稿纸画板**：点击顶部铅笔图标，呼出全屏透明涂鸦画板，支持在屏幕上随手圈画演算，支持一键清屏与收起。
- **答题卡大纲**：点击答题卡抽屉，清晰一览已答/未答/正误情况，点击题号快速跳转。
- **更多菜单 (`···`)**：
  - **星标收藏**：将重难点题加入收藏夹。
  - **主题切换**：支持【日间纯白】、【护眼豆沙绿】、【极客深色】三套护眼主题。
  - **AI 解析设置**：配置大模型密钥与地址。
  - **重新作答**：清除本题答案，重新作答检验记忆。

### 3. 双出题模式
- **背题模式**：选完选项立即判定对错（正解翡翠绿、错解珊瑚红），即时展开官方考点精解与 AI 解析。
- **做题模式**：模拟真实考试，做题过程中隐藏答案与对错，全部做完后交卷，系统自动生成**得分卡与成绩报告**，并一键切换为全卷解析模式。

### 4. 艾宾浩斯遗忘曲线错题复习
- 错题自动记录首次做错时间戳与复习轮次。
- 依据 **1天、2天、4天、7天、15天** 抗遗忘周期，智能推荐进入遗忘临界期的错题组，打破传统无序刷题，实现科学抗遗忘。

### 5. AI 名师深度流式解析
- 针对任何题目一键连线大语言模型（默认预设 **DeepSeek** 官方接口，几毛钱刷几千题）。
- 以打字机流式输出：
  1. **【考点本质】**：一句话点破考查的核心概念与法规背景；
  2. **【正解与混淆项排除】**：精准剖析为什么选该项，指出干扰项的陷阱；
  3. **【秒记口诀】**：提供押韵好记的联想记忆法。

## 二、 极速启动与手机端使用

### 1. 本地启动服务
在项目根目录下通过 `uv` 运行：
```bash
uv run python serve.py
```

终端将打印可用访问地址：
- 💻 **电脑端**：`http://localhost:8080`
- 📱 **手机端（同一 WiFi 下）**：终端提示的局域网 IP（例如 `http://10.30.249.139:8080`）

### 2. 手机端“一键变原生 App”
- **iPhone (Safari)**：打开网址 ➔ 点击底部【分享】图标 ➔ 选择【添加到主屏幕】。
- **Android (Chrome/Edge)**：打开网址 ➔ 点击右上角菜单 ➔ 选择【添加到主屏幕】或【安装应用】。
- **完全离线运行**：程序内置 Service Worker，添加主屏幕后，电脑关机、手机断网亦可全功能秒开离线刷题！

## 三、 免费部署到公网 (随时随地免电脑刷题)

将 `web/` 文件夹免费部署到 **Vercel**、**Cloudflare Pages** 或 **GitHub Pages**：
- 部署目录设置为 `web/`。
- 构建命令留空即可。
部署后即拥有永久免费的 HTTPS 专属刷题网站，手机随时通过移动网络访问。
