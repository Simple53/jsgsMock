# file2quiz

> 将各种文档/题库（PDF）转换为现代化移动端离线刷题应用。**纯扁平化设计、无渐变、无任何阴影、杜绝任何 Emoji**，采用全套精巧原生 SVG 矢量图标。深度支持每日打卡与数据统计、全局题目搜索、艾宾浩斯遗忘曲线复习、全真模拟组卷保存、学情考分预测、AI 品牌多服务商图标面板（支持在线拉取模型与搜索切换）与外部题库导入。

- 📦 **GitHub 仓库**：[Simple53/file2quiz](https://github.com/Simple53/file2quiz)
- 🛠 **开发与运行环境**：现代极速包管理器 **uv** (Python 3.13)

---

## 一、 核心功能特色

### 1. 底部五大专属工作台
- 📚 **【练习】**：
  - **每日励志标语**：首页纯净置顶，每日精选一句名言激励备考。
  - **打卡与全局搜索图标**：纯 SVG 矢量图标设计（打卡带未完成提示红点）；支持实时模糊检索 1100 道真题与解析，即搜即刷。
  - **1~5 颗星掌握度评分**：动态根据用户真实正确率实时评定知识点薄弱度。
  - **刷题前参数确认**：点击科目弹出模式（背题/做题）、题量（5/10/15/20/不限）、**随机乱序出题**确认卡片。
- 📕 **【错题本】**：
  - **常规错题回顾**：清晰罗列做错的题目，支持单题精练或一键移出。
  - **艾宾浩斯遗忘曲线强化**：依据 1/2/4/7/15 天抗遗忘临界窗口，智能筛选到期错题组，科学抵抗遗忘。
- 📝 **【模拟考试】**：
  - 支持快捷组合全真模拟卷（自定义试卷名、抽取 20/50/100 题）。
  - **试卷永久保存在本地试卷库**：随时调出重考或回溯。
  - 沉浸式考试交卷，系统自动生成**得分报告与全卷答案解析**。
- 📊 **【数据统计】**：
  - 学情大看板：已练题目数、综合正确率、连续打卡天数。
  - **智能考分预测**：按 100 分制给出当前综合预估分、备考能力评级与改进建议。
  - 各科目完成进度与掌握度横向进度条。
- ⚙️ **【个人设置】**：
  - **打卡数据统计看板**：连续打卡天数、总打卡天数与近 7 天打卡日历点阵。
  - 设置默认做题模式（背题模式 vs 做题模式）。
  - 设置**主题外观是否自动跟随手机系统暗黑模式**。
  - **题库导入与更新**：支持导入自定义 JSON 题库，随时扩充题目；支持一键导出备份。

### 2. 刷题工作台与交互手势
- 🔄 **左右滑屏切题**：在题目区域向左滑切到下一题，向右滑切到上一题。
- 🛠 **顶部全平铺工具栏（无折叠、无 Emoji）**：
  - `✕` **返回退出**：自动保存当前进度并返回。
  - ⏱ **正向计时器**：秒级记录答题时长。
  - ✏️ **草稿画板**：全屏透明画板随手演算，**支持精准“撤销一步”(Undo)** 与清屏。
  - ★ **星标收藏**：点亮黄色星标加入收藏夹。
  - ☀️/🌙/👁 **主题切换**：通过太阳（日间纯白）、月亮（极客深色）、护眼眼睛（豆沙绿）专属 SVG 图标循环切换。
  - ⚙️ **AI 助手配置**：调出大模型接口与模型切换抽屉。
  - 📋 **答题卡**：网格答题卡，做对/做错/已选/未选直观显示，点击题号快速跳转。

### 3. 多 AI 模型服务商与在线获取
- **供应商图标面板**：横向平铺精制品牌 Logo 卡片：
  - **DeepSeek**（深度求索）
  - **Kimi**（月之暗面 Moonshot）
  - **Qwen**（阿里通义千问）
  - **Zhipu**（智谱清言 / GLM）
  - **ChatGPT**（OpenAI）
  - **硅基流动**（SiliconFlow 高速推理平台）
  - **自定义 Custom**（兼容任意 OpenAI 协议接口）
- **智能参数预填与在线模型获取**：
  - 选中服务商自动预填官方 API 端点；
  - 输入 API Key 后支持**一键在线获取服务商最新模型列表**（`/models`）；
  - 支持模型**关键词实时搜索过滤**与点击即选；
- 针对每道题点击【一键精讲】，以**打字机流式输出**核心考点、混淆项排除逻辑与记忆口诀。

## 二、 快速上手与手机端使用

### 1. 本地启动服务
在项目根目录下通过 `uv` 启动：
```bash
uv run python serve.py
```
- 💻 **电脑端**：直接打开 `http://localhost:8080`
- 📱 **手机端（同一 WiFi 下）**：打开终端显示的局域网 IP（例如 `http://10.30.249.139:8080`）

### 2. 添加到手机主屏幕 (离线 PWA)
- **iPhone (Safari)**：点击底部【分享】图标 ➔ 选择【添加到主屏幕】。
- **Android (Chrome/Edge)**：点击右上角菜单 ➔ 选择【添加到主屏幕】或【安装应用】。
- **完全脱离电脑运行**：内置 Service Worker，添加到桌面后，电脑关机、手机断网亦可秒开完整离线刷题！
