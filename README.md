# 考点刷题助手（移动端 PWA & AI 智析）

专为考编、高校教师岗前培训等考试定制的轻量级题库刷题工具。基于 **纯扁平化冷色系（冰蓝）** 设计，无任何渐变色与阴影，支持手机全屏刷题、答案折叠展开与 DeepSeek 等大模型智能解析。

---

## 一、 功能亮点

1. **五大科目题库全收录**：
   - 包含已提取好的 1100 道真题（单选、多选、判断），覆盖：
     - 《习近平总书记教育重要论述》
     - 《高校教师职业道德规范》
     - 《高等教育学》
     - 《高等教育心理学》
     - 《高等教育法规》
2. **纯扁平化冷色系 UI（无阴影、无渐变）**：
   - 冰蓝主题、纯白底色、高对比度阅读体验。
   - 选项圆角矩形按钮、纯色边框，点击即时反馈（对绿/错红）。
   - 顶部做题进度条，底部上一题/下一题及星标收藏。
3. **答案与知识点折叠**：
   - 默认隐藏答案及官方解析，做完后或点击【查看答案及解析】展开。
4. **AI 深度剖析（支持 DeepSeek 等）**：
   - 点击【🤖 AI 深度剖析】，AI 会针对当前题目的考点本质、混淆选项辨析、背诵技巧进行流式输出。
   - 在页面右上角 ⚙️ 设置中填入自己的 API Key（如 DeepSeek 密钥），按需调用，成本几近于零。
5. **做题记录本地持久化**：
   - 自动保存做题记录、答题状态、错题本与收藏夹在手机端 `localStorage`，无需账号、断网可用。
6. **手机原生 App 体验（PWA）**：
   - 手机自带浏览器打开后，点击【添加到主屏幕】，即生成独立 App 图标，全屏沉浸式刷题。

---

## 二、 极速启动与手机端使用

本项目使用现代极速包管理器 `uv` 进行依赖管理。

### 1. 启动本地服务
在项目根目录下运行：
```bash
uv run python serve.py
```

终端将打印访问地址：
- 💻 **电脑端浏览器**：直接访问 `http://localhost:8080`
- 📱 **手机端（同一 WiFi 下）**：访问终端提示的局域网 IP（例如 `http://10.30.249.139:8080`）

### 2. 手机端“一键变 App”操作：
- **iPhone (Safari)**：打开网址 -> 点击底部中间【分享】按钮 -> 选择【添加到主屏幕】。
- **Android (Chrome/Edge/微信外部浏览器)**：打开网址 -> 点击右上角菜单 -> 选择【添加到主屏幕】或【安装应用】。

## 三、 自由部署到公网（随时随地离线刷）

如果你希望不依赖局域网，出门随时随地在手机上刷：
只需将 `web/` 文件夹上传至任何免费静态托管平台（**Cloudflare Pages**、**Vercel** 或 **GitHub Pages**）：
- 项目根目录设置为 `web/`。
- 构建命令留空即可。
部署后会得到一个独立的专属网址，永久免费、全球加速，且答题进度全在个人手机本地！

---

## 四、 重新解析或添加新 PDF 题库

若后续有新题库 PDF，放入项目根目录后，运行：
```bash
uv run python parse_quiz.py
python -c "import shutil; shutil.copy('quiz_data.json', 'web/quiz_data.json')"
```
即可完成一键解析更新。
