# file2quiz

> 将各种文档/题库（PDF）转换为现代化移动端离线刷题应用。**纯扁平化设计、无渐变、无任何阴影、杜绝任何 Emoji**，采用全套精巧原生 SVG 矢量图标。深度支持艾宾浩斯遗忘曲线复习、全真模拟组卷保存、多 AI 服务商/模型自由切换与流畅滑屏手势切题。

- 📦 **GitHub 仓库**：[Simple53/file2quiz](https://github.com/Simple53/file2quiz)
- 🛠 **开发与运行环境**：现代极速包管理器 **uv** (Python 3.13)

---

## 一、 核心功能特色

### 1. 底部四大专属工作台
- 📚 **【练习】**：
  - 收录已解析的 5 大科目共 1100 道真题（单选、多选、判断）。
  - **1~5 颗星掌握度评分**：动态根据用户真实正确率实时评定知识点薄弱度。
  - 题量进度追踪，**【继续上次 ›】** 一键秒回离开题号。
- 📕 **【错题本】**：
  - **常规错题回顾**：清晰罗列做错的题目，支持单题精练或一键移出。
  - **艾宾浩斯遗忘曲线强化**：依据 1/2/4/7/15 天抗遗忘临界窗口，智能筛选到期错题组，科学抵抗遗忘。
- 📝 **【模拟考试】**：
  - 支持快捷组合全真模拟卷（自定义试卷名、抽取 20/50/100 题）。
  - **试卷永久保存在本地试卷库**：随时调出重考或回溯。
  - 沉浸式考试交卷，系统自动生成**得分报告与全卷答案解析**。
- 📊 **【做题历史】**：
  - 【练习历史】：各科累计练题数与正确率一览。
  - 【考试历史】：历次模拟考卷的得分与提交时间存档。

### 2. 刷题交互与平铺工具栏
- 🔄 **左右滑屏切题**：在题目区域任意向左/向右滑屏，手势丝滑切换下一题/上一题。
- 🛠 **顶部全平铺工具栏（无折叠、无 Emoji）**：
  - `✕` **返回退出**：自动保存当前科目进度并返回。
  - ⏱ **正向计时器**：秒级记录答题时长。
  - ✏️ **草稿模式**：全屏透明画板随手演算，**支持精准“撤销一步”(Undo)** 与清屏。
  - ★ **星标收藏**：点亮黄色星标加入收藏夹。
  - 🎨 **主题切换**：支持【日间纯白】、【护眼豆沙绿】、【极客深色】一键轮换。
  - 🤖 **AI 助手**：随时调出大模型参数与模型切换抽屉。
  - 📋 **答题卡**：网格答题卡，做对/做错/已选/未选直观显示，点击题号快速跳转。

### 3. 多 AI 模型服务商自由接入
- 支持主流 OpenAI 规范大模型服务商一键切换：
  - **DeepSeek** (`deepseek-chat`, `deepseek-reasoner`)
  - **OpenAI** (`gpt-4o-mini`, `gpt-4o`, `gpt-3.5-turbo`)
  - **Kimi / Moonshot** (`moonshot-v1-8k`, `moonshot-v1-32k`)
  - **硅基流动 SiliconFlow** (`Qwen2.5`, `DeepSeek-V2.5`)
  - **自定义 Custom**：支持填入任意兼容的 Base URL 与模型名称。
- 针对每道题点击【一键精讲】，以**打字机流式输出**核心考点、混淆项排除逻辑与记忆口诀。

## 二、 快速上手与手机端使用

### 1. 本地启动服务
在项目根目录下通过 `uv` 启动：
```bash
uv run python serve.py
```
- 💻 **电脑端**：直接打开 `http://localhost:8080`
- 📱 **手机端（同一 WiFi 下）**：打开终端显示的局域网 IP（例如 `http://10.30.249.139:8080`）

### 2. 添加到手机主屏幕 (离线 PWA)
- **iPhone (Safari)**：点击底部【分享】图标 ➔ 选择【添加到主屏幕】。
- **Android (Chrome/Edge)**：点击右上角菜单 ➔ 选择【添加到主屏幕】或【安装应用】。
- **完全脱离电脑运行**：内置 Service Worker，添加到桌面后，电脑关机、手机断网亦可秒开完整离线刷题！

## 三、 公网免开机免费托管

只需将项目中的 `web/` 文件夹上传至 **Cloudflare Pages**、**Vercel** 或 **GitHub Pages**：
- 部署目录设置为 `web/`，构建命令留空。
- 部署成功后即可获得专属永久免费的 HTTPS 网址，手机随时随地通过移动网络刷题！
