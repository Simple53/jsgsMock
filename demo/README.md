# 高校教师资格考试使用演示与教程

包含课程观看辅助脚本与跨平台刷题工具的项目地址、功能简介及演示视频。

---

## 1. jsgsHelper

- 项目地址：https://github.com/Simple53/jsgsHelpler
- 功能简介：浏览器插件脚本，辅助完成课程观看，支持后台播放、跨课联播、倍速播放、进度拖拽等。具体安装视频教程参见同目录下 jsgsHelper教程.mp4 或 index.html。

---

## 2. jsgsMock

- 项目地址：https://github.com/Simple53/jsgsMock
- 网址入口：https://simple53.github.io/jsgsMock
- 下载地址：https://github.com/Simple53/jsgsMock/releases/tag/v1.4.7
- 功能简介：基于PWA网页的刷题工具，实现了网页端、Windows、安卓、iOS、Mac等多模式。所有用户的进度保存在本地设备中，电脑和手机可以通过导入导出备份实现同步。内容涵盖官网最新题库、视频播放、错题收藏、做题统计、AI助教等功能，界面简洁易上手。同步功能视频参见同目录下 jsgsMock教资刷题助手教程.mp4 或 index.html。
