# 高校教资备考工具

## 1.jsgsHelper
项目地址：https://github.com/Simple53/jsgsHelpler
功能简介：浏览器脚本插件。辅助完成课程观看，后台播放、跨课联播、倍速播放、进度拖拽等。
安装教程：参见同目录下 jsgsHelper教资播放助手教程.mp4 或 index.html

## 2.jsgsMock
项目地址：https://github.com/Simple53/jsgsMock
网址入口：https://simple53.github.io/jsgsMock
下载地址：https://github.com/Simple53/jsgsMock/releases/tag/v1.4.7
功能简介：基于PWA网页刷题工具，实现了网页端、WIN、安卓、IOS、MAC等多模式，所有用户的进度都会保存在设备中，电脑和手机可以通过导入导出备份实现同步，用户端尚未完成测试，内容涵盖了官网最新题库、视频播放、错题收藏、做题统计、ai助教等等功能，界面简洁容易上手。
使用教程：参见同目录下 jsgsMock教资刷题助手教程.mp4 或 index.html
